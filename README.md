# Cast

**Fishing companion · Created by Theo Jandhyala**

Cast helps anglers explore waters, record catches in a photo journal, review fishing sessions and prepare trips with available weather and tides.

## Creator

[Theo Jandhyala](https://www.linkedin.com/in/theo-jandhyala/) is an independent app developer based in the Cheltenham area, England, and the creator of Cast, DEADSET, Reclaim and LifeScore. His work includes product planning, interface design, development, testing and release preparation.
